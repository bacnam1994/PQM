## 1. PHÂN LOẠI CÁC DẠNG KHIẾM KHUYẾT (GAP CLASSIFICATION TAXONOMY)

- **GAP-L01 — Local Mutation**: UI/Hook trực tiếp thay đổi persistent data ngoài Application Service.
- **GAP-L02 — Local Business Logic**: UI/Hook tự quyết định logic nghiệp vụ hoặc phân giải điều kiện thay vì Domain Engine.
- **GAP-L03 — Local Status Mutation**: Thay đổi trạng thái (`status`, `workflowStatus`, `qualityStatus`) không qua State Machine.
- **GAP-L04 — Local Transition**: Chuyển trạng thái A → B tùy tiện không qua kiểm tra khế ước FSM.
- **GAP-L05 — Local Authorization**: Component/Hook tự `if (role === ...)` mà không qua Authorization Guard tập trung.
- **GAP-L06 — Local Audit**: Mutation xảy ra nhưng thiếu Audit Event hoặc ghi trùng lặp (Double Audit) từ UI.
- **GAP-L07 — Local Validation**: Ràng buộc dữ liệu quan trọng chỉ nằm ở UI form, không được bảo vệ tại Application Service/Domain.
- **GAP-L08 — Local Snapshot**: Tự tạo hoặc tính toán lại Evaluation Snapshot ngoài canonical snapshot builder.
- **GAP-L09 — Local Evaluation**: UI tự phân giải PASS / FAIL / PENDING thay vì gọi Canonical Status Resolver.
- **GAP-L10 — Local Document Generation**: Tài liệu CoA tự nội suy quy tắc thay thế ngoài Authoritative Snapshot.
- **GAP-L11 — Local AI Mutation**: AI Assistant/Clearance có callback kích hoạt mutation trực tiếp hoặc thiếu review.
- **GAP-L12 — Local Bulk Mutation**: Import dữ liệu hàng loạt không qua pipeline kiểm duyệt từng thực thể.
- **GAP-L13 — Local Recovery Mutation**: Auto-heal / cron can thiệp dữ liệu ngoài workflow kiểm soát an toàn.
- **GAP-L14 — Local Admin Override**: Quản trị viên ADMIN được cấp quyền bypass Release Gate hoặc Security Invariants.
